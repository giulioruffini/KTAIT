00What the project is for

One rule governs the whole repository: standard results of algorithmic information theory may be assumed; every KT corollary must be proved from them, with no sorry. The point is not to re-derive mathematics that is already settled. It is to check that KT's own claims follow from what it says it assumes.

A second purpose emerged and is now arguably the more useful one: making the theory's structural mistakes impossible rather than merely discouraged. Several errors that reached drafts — treating a class as a rung of composition, an admissibility condition that admitted precisely what its source paper excludes, an agent typed as a rival to a pattern — are category errors. A type checker catches those on every build, without anyone remembering to look.

The analogy: dimensional analysis

A type system is dimensional analysis for concepts. You cannot add a length to a time — not because it is discouraged, but because the expression is meaningless, and the check catches it before any number is computed. Here the same check runs over concepts like pattern, agent, regulator, kind, and collective.

01Reading Lean: three ideas

Everything in the repository is built from these. The examples are self-contained — no KT in them — so you can check each against your own intuition first.

Idea 1 a structure is a record with named slots
structure Point where
  x : Nat
  y : Nat

def p : Point := ⟨3, 4⟩

Reading itThe colon means "has type". The angle brackets mean "here are the slot values, in order". This is a named tuple, exactly like writing a state as a list of components.

Idea 2 a slot can hold a proof, and then it constrains what exists
structure EvenNumber where
  val    : Nat
  isEven : val % 2 = 0        -- a STATEMENT, not data

def four : EvenNumber := ⟨4, by decide⟩   -- fine

-- def five : EvenNumber := ...   IMPOSSIBLE: no proof exists

Reading itThe second slot's type is a claim, and the only thing that fills such a slot is a proof of it. So there is no odd EvenNumber — not by convention, but because the object cannot be built.

Green field names throughout this page are slots of this kind. The physics analogue: a quantum-state record carrying its own normalization proof, so an unnormalized wavefunction cannot be handed over as a state.

Idea 3 a predicate over one carrier, versus two separate types
-- OPTION A: evens as their own type.
structure EvenNumber where
  val : Nat
  isEven : val % 2 = 0
-- "every even number is a number" CANNOT BE SAID: different types.

-- OPTION B: evens as a predicate on the one carrier.
def IsEven (n : Nat) : Prop := n % 2 = 0
-- Now it is sayable, and provable.

Reading itOption A looks tidier and is a trap. To say the evens are contained in the naturals, they must share a carrier.

This is the most consequential decision in the newest module. Pattern, Persist! says the agent is a pattern, there is nothing over and above it, and that the persistent patterns strictly contain the agents. That is Option B. An earlier draft used Option A, and the paper's own claim became unsayable.

02Assumed, defined, proved

Three categories, kept strictly apart. Confusing them is how a formalization comes to look more impressive than it is.

Assumed — named hypotheses, never global axioms

Invariance, symmetry of information, the coding theorem, Kraft counting, Bayes: standard, and assumed. But how they are assumed matters. Each is stated as a named proposition about a frame and passed to the theorems that need it, rather than declared as a global axiom.

Why that distinction is not pedantry

A global axiom asserting a law for every frame would be inconsistent here: one can hand-build a frame with zero slack that violates it, and derive falsehood. Stating the laws as hypotheses keeps every corollary a sound implication, and lets #print axioms report Lean's core only. A toy model then witnesses that the hypotheses are satisfiable, so the theorems are not vacuously true.

Defined — where the content and the risk both sit

Definitions cannot be false. They can be unfaithful — a bad rendering of what a paper says — and no theorem rescues a definition that mis-states its source. This is the real failure mode. An adversarial audit of the newest module against its paper found four unfaithful definitions, each individually plausible, including one whose admissibility condition admitted the very case the paper excludes by name.

Proved — and worth reading carefully

Two kinds, and they are not equally strong. Some theorems are general, quantified over all frames. Others are about hand-built toy witnesses, and establish that the definitions are coherent and inhabited — that one can construct the intended object and nothing contradicts. Both are worth having; only the first is a discovery.

Where the real teeth are

Not in the theorems, but in the guards — statements recorded as ones that must fail to compile. The build passes because Lean rejects them. If a future edit ever made a bad statement legal, the build breaks and says so. Guards are the part that keeps working while nobody is looking.

04How drift is prevented

The discipline exists because it was once absent, and that had consequences. An adversarial review found a published proposition proved from a hypothesis false in the regime it named. Fixing it exposed two holes that had nothing to do with the mathematics: the fix sat uncommitted while the paper publicly claimed the result was machine-checked and pointed readers at the repository, which still served the false hypothesis; and nothing checked that paper against the Lean at all.

So it is enforced rather than remembered. A sync script requires that proofs be sorry-free, that the status paper list every module and non-helper theorem, and that every declaration a paper cites by name still resolves. A pre-push hook runs it and blocks the push on failure; CI runs it again on every push, so drift cannot land even if a hook is bypassed.

The rule behind all of it

The Lean and the paper ship together. A theorem that is not in the status paper does not exist. And "machine-checked" is a promise about the public repository, not about somebody's laptop.

05What is deliberately absent

  • Thermodynamics. The Landauer pricing of persistence needs a physical model — a heat bath, a temperature, a notion of physical realization — that the AIT frame does not supply. The relevant conjecture is recorded as not stateable here, which is itself a finding, rather than quietly promoted.
  • Substrate dynamics. Time is an index, not an evolution.
  • Composition. There is no meta-agent operator yet, so the nested hierarchy from particle to planetary system cannot be expressed — though meta-persistence is the natural hook.
  • Most of the graded coordinates. Regulator locus and objective self-reference are represented; thermodynamic regime, plasticity, and counterfactual depth are not.

Listing these is part of the discipline. A formalization that does not say what it omits invites the reader to assume it omits nothing.
